# Changelog

## 1.0.0

- Rebuilt the repository around a canonical CSV dataset.
- Added JSON and YAML dataset formats.
- Added generated plain text, comma-separated text, typeahead JSON, alpha-2, and alpha-3 distribution files.
- Added ISO alpha-2, alpha-3, numeric, official name, common name, and flag fields.
- Updated outdated names such as Eswatini, North Macedonia, Türkiye, and Czechia through current ISO naming.
- Fixed encoding issues by standardizing all files as UTF-8.
- Added validation and generation scripts.
- Added end-user documentation for schema, usage, sources, and methodology.
- Added citation and Zenodo metadata.
